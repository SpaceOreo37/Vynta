# Icons

Add PNG files here before publishing:

- `icon16.png`  — 16×16px  (used in the Chrome toolbar)
- `icon48.png`  — 48×48px  (used in chrome://extensions)
- `icon128.png` — 128×128px (used in the Chrome Web Store)

The extension loads and runs without icons during local development —
Chrome will just show a default grey puzzle piece icon.
